모바일 화면 중앙 정렬 및 빠른메뉴 가림 수정

- 본문과 BOSS 표를 휴대폰 화면 너비 기준으로 다시 중앙 정렬
- 우측 빠른메뉴가 표의 마지막 열을 덮지 않도록 기본 상태를 화면 밖으로 접음
- 접힌 상태에서도 각 메뉴 버튼의 끝부분 18px이 보여 메뉴 존재를 확인 가능
- 접힌 버튼을 한 번 누르면 빠른메뉴 전체가 펼쳐짐
- 펼쳐진 상태에서 메뉴를 다시 누르면 해당 화면으로 접속
- 해당 화면이 열리면 빠른메뉴가 자동으로 다시 접힘
- 빠른메뉴를 펼친 뒤 3초 동안 선택하지 않으면 자동으로 다시 접힘
- 채팅·스케줄·BOSS·경매장·통합DB 버튼을 서로 다른 색상으로 구분
- BOSS 표 열 너비를 화면 안에서 균등하게 맞추고 긴 문자는 말줄임 처리
- 핸드폰 화면에서 기존 중앙 기준을 유지하면서 미르: 진 로고만 오른쪽 12px 보정
- 모바일 메인 경매장에 이름 확인 중인 매물도 포함해 최대 8개 표시
- 모바일 경매장 목록 높이를 늘리고 내부 스크롤 지원
- 빠른메뉴 통합DB는 아이템 표를 강제로 열지 않고 최신 통합 DB 첫 화면으로 연결
- 모바일 빠른메뉴 채팅창을 휴대폰 화면 높이에 맞게 고정
- 채팅 메시지만 스크롤되며 닉네임·메시지·전송 입력 영역은 항상 하단에 표시
- 휴대폰 키보드와 안전 영역을 고려해 입력 영역 하단 여백 적용

PC·핸드폰 상단 디자인 통합

- PC와 핸드폰 모두 붓글씨 미르: 진 로고를 상단 중앙에 배치
- PC 상단 왼쪽에 실시간 게임 정보 안내 카드 추가
- PC 상단 오른쪽에 데이터 연결 상태와 마지막 갱신 시각 표시
- 핸드폰에서는 로고 아래에 두 안내 카드를 나란히 배치해 화면 폭에 맞춤
- 상단 배경에 옅은 수묵 산수 질감과 청록·적색 구분선 적용
- 기존 로고를 중복 생성하지 않고 현재 로고 영역 하나만 사용

실제 수묵화 배경 이미지 추가

- CSS 도형 대신 실제 생성된 수묵 산수 PNG 그림을 상단 배경으로 적용
- 양쪽 산과 소나무는 보이고 중앙 미르: 진 로고 영역은 밝게 유지
- PC와 핸드폰에서 같은 그림이 각 화면 폭에 맞춰 표시
- 배경 파일: assets/wuxia-ink-mountain-header-v18.png

상단 여백 축소 및 빠른메뉴 위치 조정

- PC 상단 높이를 126px로 줄이고 로고·안내 카드를 한 줄 중앙에 맞춤
- 태블릿 상단 높이를 116px로 축소
- 핸드폰 상단 높이를 122px로 줄이고 로고 아래 기준선까지만 표시
- 핸드폰에서는 상단 안내 카드 두 개를 숨겨 불필요한 세로 여백 제거
- 수묵화 배경의 위쪽을 잘라 산수 그림과 로고 중심이 바로 보이도록 조정
- 핸드폰 빠른메뉴는 줄어든 상단 바로 아래 128px 위치에서 시작
- 빠른메뉴 버튼 간격과 높이를 줄여 작은 화면에서도 화면을 과하게 덮지 않게 조정
