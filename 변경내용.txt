미르진 홈페이지 모바일 개선본

적용 내용
1. 통합 DB를 열면 아이템 실제 목록이 즉시 표시되도록 변경
2. 미르진 로고 개선 및 아라문파 로고를 나란히 배치
3. 메인 실시간 채팅을 오래된 글 → 최신 글 순서로 표시해 최신 글이 맨 아래에 오도록 변경
4. 정보게시판 최신 글은 제목만 표시
5. 모바일 상세창 제목이 상단 헤더에 가려지지 않도록 수정
6. 상단 햄버거 메뉴 제거, 우측에 BOSS·경매장·통합 DB 빠른 버튼 배치
7. 스케줄 등록을 날짜·시간·내용·등록 방식으로 간소화
8. 실시간 채팅을 전체 채팅 한 개로 통합

구성
- index.html
- assets/mirjin-emblem.webp
- assets/aramun-emblem.webp

위 세 파일의 상대 위치를 유지해 홈페이지에 업로드하면 됩니다.

추가 교정
- 미르:진은 그림 없이 무협풍 글자만 표시하고, 누르면 페이지가 새로고침되도록 변경
- 아라문파 문장을 더 크고 화려한 무협게임풍 문장으로 교체
- 통합 DB 진입 시 검색창 자동 초점을 제거하여 휴대폰 키보드가 강제로 올라오지 않도록 수정
- 서비스 상세창이 열려 있는 동안 우측 채팅·스케줄 패널이 덮지 않도록 수정
- BOSS·경매장·통합 DB를 스케줄 바로 아래에 동일한 탭 모양과 간격으로 배치

최종 교정(v3)
- 미르:진 글자를 붓글씨가 바람에 흩날리는 느낌으로 다듬고, 해당 글자만 새로고침 기능 유지
- 아라문파는 바로가기 기능 없이 장식된 무협풍 글자만 표시
- 채팅·스케줄·BOSS·경매장·통합 DB 빠른 메뉴를 하나의 세로 목록으로 합치고 모든 간격을 동일하게 조정
- 통합 DB 검색 중 입력창을 강제로 해제하던 처리를 제거해 한글이 자모로 분리되지 않고 정상 조합되도록 수정

로고 이미지 교체(v4)
- 미르:진 글자형 로고를 직접 제작한 투명 배경 무협풍 붓글씨 이미지로 교체
- 로고 이미지를 누르면 기존과 동일하게 홈페이지 새로고침

경매장 개선(v5)
- 경매장 목록의 글자·사진·가격·남은 시간을 키우고 항목 간 구분을 강화
- 상세 화면의 아이템 사진과 핵심 가격 정보를 크게 표시하고 옵션을 읽기 쉬운 카드로 정리
- 아이템 사진 확대창을 경매장 상세창보다 항상 앞에 표시
- 수-0, 수 0-0, 수0 및 해당 표기가 이어진 OCR 이름을 해골소환(물)로 통일
- 해골소환(물)의 경매장 분류를 무공서로 고정

상단·빠른 메뉴 교정(v6)
- 우측 채팅 숫자를 실제로 불러온 전체 채팅 데이터 개수로 표시
- 우측 스케줄 숫자를 실제로 불러온 전체 스케줄 데이터 개수로 표시
- 상단 아라문파 문구 완전 제거
- 미르:진 붓글씨 이미지 크기를 데스크톱과 휴대폰 모두 확대

로고 위치 교정(v7)
- 미르:진 로고를 상단 영역의 가로·세로 정중앙에 고정
- 화면 폭이나 우측 요소의 유무와 관계없이 중앙 위치를 유지
