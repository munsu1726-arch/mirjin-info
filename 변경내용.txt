홈페이지 v9 수정 내용

1. 실시간 채팅
- 우측 빠른메뉴에서 채팅을 열었을 때 메시지 목록 아래 입력칸이 항상 보이도록 수정
- 채팅창 높이를 휴대폰 화면 안으로 제한
- 닉네임, 메시지, 전송 버튼을 채팅창 하단에 고정
- 전체 채팅 하나만 표시

2. 최신 통합 DB
- 이전 통합DB 2세대, 3세대 화면 생성 코드 제거
- 바깥 통합DB 창 위에 아이템/드랍/스킬 창이 다시 뜨던 이중 팝업 제거
- 최신 통합DB 창 하나만 사용
- 아이템, 드랍 정보, 직업별 스킬을 누르면 같은 창의 아래 표 내용만 변경
- 표의 행을 누르면 별도 팝업 없이 해당 행 바로 아래 칸에 상세 정보 표시
- 한 화면에 많은 데이터를 볼 수 있는 엑셀식 표 유지

3. 교체 원칙
- 이전 화면 위에 새 화면을 덧붙이지 않고 이전 화면 생성 코드를 제거한 뒤 교체

검사
- 이전 DB v2/v3 실행 코드가 결과 파일에서 제거된 것을 확인
- 포함된 실행 스크립트 21개 구문 검사 통과
